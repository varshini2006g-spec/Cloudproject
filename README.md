# Student Result Management System

## Project Overview
A Java application that calculates student marks, total, average, and pass/fail status.

## Technologies Used
- Java 21
- Docker
- AWS EC2 Ubuntu

## Features
- Student name and department input
- Three subject marks
- Total and average calculation
- Pass or fail result

## Run Using Docker

Build:
sudo docker build -t student-result .

Run:
sudo docker run -it --rm student-result
