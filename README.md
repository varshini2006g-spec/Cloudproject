# Student Result Management System

## Project Overview
A Java-based application to calculate student marks,
total, average, and pass/fail status.

## Technologies Used
- Java 21
- Docker
- AWS EC2 Ubuntu

## Features
- Student name and department input
- Three subject marks input
- Total and average calculation
- Pass or fail result

## Run Using Docker

Build the image:

    sudo docker build -t student-result .

Run the application:

    sudo docker run -it --rm student-result
